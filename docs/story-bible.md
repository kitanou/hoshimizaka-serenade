## 2. 世界観 [確定]

- **星見坂（ほしみざか）**: 海へくだる長い坂道と桜並木のある街。街灯がぽつりぽつりと海まで続く（slope_night）
- **星見坂の丘**: 坂のてっぺん。子ども時代から星見の場所。誕生日の夜に毎年願い事をするミサキの習慣がある（day2・楓の証言）
- **学校**: 主人公が4/8に転入する高校。**[決定案A] 校名は「星見坂高等学校」**（街名と統一。承認まで脚本では校名を出さない）。二年B組、屋上、廊下、天文部部室（ほぼ物置）がある

- **時代**: 1996年4月〜。携帯電話・PC通信は存在しない時代の空気（文房具・新聞部・手書きの入部届）

### 2.1 星降りの伝説 [確定]

- この夏、**三十年ぶりの流星群**が来る（day1・ミサキ）

## 8. 決定案A の設計内容

### 8-1 「七年前の約束」（①）
1989年夏、転出前夜。10歳のユウキとミサキは丘で夏の大三角の下にいた。ミサキが「この街では30年に一度、大きな流星群が来る。次は7年後の夏」と教え、2人で約束する――**「その夜、かならずこの丘にもどれ。いっしょに流れ星を見よう」**。ユウキは子どもの冗談まじりの記憶しかなく（day2 で「約束?」と空白 → 布石と矛盾しない）、ミサキは7年間、本気で守り続けた。day1 の予感ルート「流星群いっしょに見るね」（promised_misaki）は同じ約束の 1996年での更新、day3 の「ぜったい、また会いに来る」は引っ越し当日の言葉（記憶に残っている方）。
- ミサキルート M-core-1 の核心 = 「覚えていなかった自分」との対峙。M-core-2 = 7年前の約束の「答え」を今の気持ちで言い直す（GOOD/BAD 分岐）
- 伝承（day1 確定）「流星群の夜に坂のてっぺんで想いを伝えると永遠に結ばれる」とも直結

### 8-4 「もう一つの約束」と TRUE END・三十年周期の根拠（④と表#4#5）
**1966年の流星群の夜、丘で7歳の少年（後の冬華の父）が、見知らぬ転出寸前の少女と「30年後、同じ夜空の下で」と交わした約束**。翌年からこの街に「星降りの伝説」が語り継がれる（day1 の伝承の由来に整合）。父は生涯この約束を追い、1994年に叶わず死別。冬華の「父の夢だった屋上観測」は、実は父の30年生のリレーの最終走者だった。
- TRUE END = 1996/8/12 夜、ミサキ・冬華・楓とともに丘/屋上観測を完遂。父の世代の約束（1966）と主人公の約束（1989）が**同じ夜にリレー完走**する「星へのセレナーデ」。TRUE END タイトル案:「三番目の流星」→ 最終案は #25 で
- TRUE END 進入: 両 GOOD 視聴（persistent）+ day5 での新フラグ star_promise（route-flow §3 維持）
- 1966年の少女（父の約束の相手）の正体は [未決] のまま #25 で確定。選択肢案:
  - (a) **相沢ユウキの母**。30年前同じ丘で約束した二家族が、30年後に子どもらを同じ街へ帰還させる構造。day1 の「どこかで会った」感覚の深い回収になる
  - (b) すでに他界した街の女性。果たされなかった約束を対照として主人公たちの「果たす」を描く
